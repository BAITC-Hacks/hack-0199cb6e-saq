# Проект

Сервис автоматического расчёта заказов поставщикам для ekt.kz.

## Правила работы

- Думай перед кодом; простота важнее.
- Меняй только то, что относится к задаче.
- Неверный код удаляй, не оставляй рядом с новым.
- Ключи бери только из `.env`, никогда не хардкодь.
- Задача готова только тогда, когда проходят тесты: `pytest -q`.
