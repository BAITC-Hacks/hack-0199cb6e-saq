# Просмотрщик готовых рекомендаций

Отдельное локальное приложение: FastAPI читает готовый CSV по `GET /recommendations`, HTML-страница показывает таблицу, фильтр SE/ИЭК и сортировку по срочности. Движок и адаптеры не импортируются, пересчёта и записи в CSV нет.

## Запуск из корня репозитория

Нужны Python 3.12 и uv. Команда использует отдельное окружение uv, без изменения зависимостей движка:

```powershell
uv run --no-project --python 3.12 --with-requirements web/requirements-viewer.txt python -m uvicorn ekt_api.viewer:app --app-dir src --host 127.0.0.1 --port 8000
```

Открыть **http://127.0.0.1:8000/**. API: **http://127.0.0.1:8000/recommendations**. Если порт занят, заменить `8000`, например, на `8765` и открыть страницу на этом порту.

По умолчанию читается `var/recommendations_real.csv` относительно корня репозитория, независимо от текущей рабочей директории. Для другого готового файла перед запуском:

```powershell
$env:EKT_RECOMMENDATIONS_CSV = 'C:\path\to\recommendations.csv'
```

Эта настройка только выбирает файл для чтения. Просмотрщик ничего не копирует и не генерирует в каталоге данных. Кнопка обновления повторно читает CSV; обновление файла движком не запускается. При ошибке чтения или формата страница показывает сообщение вместо устаревших строк.

## Формат CSV и ответа

Кодировка UTF-8, BOM допустим. Разделитель — запятая, точка с запятой или табуляция; кавычки и переносы внутри поля обрабатываются CSV-парсером.

| Поле JSON / таблицы | Допустимый заголовок CSV |
|---|---|
| `sku` | `sku` или `sku_id` |
| `supplier` | `supplier` или `supplier_id` |
| `qty_recommended` | `qty_recommended` или `recommended_qty` |
| `reason` | `reason`, `reason_short`, `reason_short.ru` или `reason_ru` |
| `urgency` | `urgency` |

Для каждого поля нужна ровно одна колонка из перечисленных вариантов. Дополнительные колонки в ответ не попадают. API возвращает массив объектов с пятью строковыми полями: количества сохраняются точно как в файле, без округления; коды не преобразуются в числа. `ИЭК`/`IEK` нормализуются в `IEK`, `Systeme Electric`/`SE` — в `SE`.

Срочность: `critical`, `high`, `medium`, `low`, `none`. Неизвестные значения остаются видимыми и сортируются в конце. CSV с одной строкой заголовков даёт пустую таблицу. Отсутствующий/недоступный файл — HTTP 503, неверный формат — HTTP 422. Содержимое строк и локальные пути в ошибки не включаются.

Страница и API работают с одного локального адреса. Внешних ресурсов, CDN, сборки фронтенда, авторизации, редактирования и отправки заказов нет. Публикация в сети не предусмотрена; запускать только на `127.0.0.1`.

## Проверка без реальных данных

```powershell
uv run --no-project --python 3.12 --with-requirements web/requirements-viewer.txt --with pytest --with httpx python -m pytest web/viewer_tests -q
uv run --no-project --python 3.12 --with-requirements web/requirements-viewer.txt python web/viewer_tests/serve_demo.py
```

Вторая команда создаёт временный синтетический CSV, запускает просмотрщик на **http://127.0.0.1:8765/** и удаляет временные данные при завершении Ctrl+C. Она не обращается к `var/recommendations_real.csv`.

При наличии Node.js поведение страницы проверяется без сторонних пакетов:

```powershell
node web/viewer_tests/test_viewer.mjs
```

Node.js нужен только для этого теста; запуск просмотрщика обходится без него.

Новая задача команды явно заменяет прежние требования Next.js, `/api/v1`, i18n и RBAC для этого отдельного демо-приложения. Существующий API-контракт и файлы `main.py` не меняются.
