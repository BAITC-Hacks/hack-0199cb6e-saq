# Текст для поля «Сдать решение»

**Название:** ЕКТ — Автозаказ поставщикам

**Описание:** Локальный Python-движок для подготовки рекомендованных заказов поставщикам Systeme Electric и ИЭК для ТОО «Электрокомплект». Решение предназначено для расчёта потребности по Excel-выгрузкам из 1С и представления рекомендаций с обоснованиями в таблице с экспортом в CSV. Менеджер по закупкам проверяет рекомендации и принимает окончательное решение о заказе.
