# DEMO — сценарий демо, видео (с ИИ-эпизодом) и питч

## 0. Подготовка к записи/показу (за 15 мин)
- [ ] `pwsh scripts/prewarm.ps1` — модель прогрета, индекс поиска построен, брифинг сгенерирован (RU и KZ).
- [ ] Production-сборка web (`npm run build && npm run start`), API запущен, датасет загружен, расчёт выполнен (кэш).
- [ ] Два окна браузера (обычное + инкогнито): **buyer** и **approver** — для «четырёх глаз».
- [ ] Масштаб 110–125%, уведомления Windows выключены, лишние вкладки закрыты, курсор крупный.
- [ ] Проверено в режиме «в самолёте»: чат, голос, поиск, брифинг работают.
- [ ] Если видео будет публичным — датасет **синтетический** (SPEC_SECURITY §6).
- [ ] Запасной вариант: записанное видео на ноутбуке и флешке.

## 1. Сквозной сценарий (он же чек-лист интеграции)
1. Логин buyer → **Главная**: брифинг ИИ, KPI.
2. **Данные** → «Загрузить демо-данные»: 12 файлов распознаны; отчёт качества: пустые количества, «Итого», чужой SKU LOOP 210 000 шт (карантин),
   сверка SE ≈×2 (предупреждение), дубликаты, «Удалено персональных данных: N» (подписи авторов комментариев).
3. **Подсказки ИИ**: «MKK10-20-20 заменён на MKK11-20-20 — перенести историю?» → Принять; «EOL» → Принять; «Бухтами/метражом» → Принять все ≥0.9.
4. **Расчёт** → параметры (сроки каналов из данных: РФ 38 / ПП 24 / УТ 12; SE 45) → Рассчитать.
5. **Рекомендации**: вкладки Systeme Electric | ИЭК, сортировка по срочности; бейдж «оценка остатка» у ИЭК.
6. Карточка SE-позиции со stockout: заливка месяцев без остатка, пунктир восстановленного спроса, ✕ разового заказа, waterfall, чипы
   «без восстановления: …», «без исключения разовых: …» (**MH3, MH4 наглядно**).
7. What-if: +в пути → количество падает; срок +10 дней → растёт (**MH1 наглядно**).
8. Карточка кабеля: «9 бухт = 2 745 м» (единицы закупки).
9. Выбрать строки → «Создать заказ» → правка −30% без причины → ошибка → с причиной → Отправить на утверждение.
10. Окно approver: сводка ИИ для утверждающего → Утвердить (попытка buyer утвердить свой → «четыре глаза»).
11. Экспорт «1С (xlsx)» → открыть файл; «Черновик письма поставщику» → копировать (надпись: отправляет сотрудник).
12. Аудит → «Проверить целостность» ✓.
13. ИИ-эпизод (§2, 1:05–2:15).

## 3. Питч (6 слайдов, 3–4 мин)
1. **Проблема и ценность** — ручной Excel, редкий расчёт, избыток и дефицит; ценность: меньше замороженных денег, меньше упущенных продаж.
2. **Что мы нашли в ваших данных** — примеры: формула среднего берёт 13 месяцев вместо 12 (можно уточнить ~на 8%); отчёты SE расходятся ≈×2;
   товар на 210 000 шт вне ассортимента; у 163 из 422 (SE) и 726 из 1 326 (ИЭК) активных позиций были месяцы без остатка; даты прибытия спрятаны
   в комментариях; коридор покрытия 1–4 месяца из вашей же разметки. Тон: «возможности уточнить», без критики.
3. **Как это работает** — конвейер (очистка → разовые → stockout → сезонность/тренд → политика → объяснение), как доказан каждый must-have (тесты).
4. **Демо** (или видео).
5. **Локальный ИИ на RU/KZ** — 4 принципа (не считает, локально, человек решает, деградация без боли) + 7 функций.
6. **Безопасность, закон, результаты и дорожная карта** — приватность клиентов (HMAC), ПД сотрудников, закон РК о ПД и об ИИ, аудит;
   бэктест; дальше: интеграция с 1С (OData/обмен), ежедневная ведомость движения, другие поставщики через умный импорт, ID клиентов.
